없음. 모든 Phase 1 질문 필수라는 기존 사용자 결정을 유지한다. 단독 F1 검증은 live·전체 기능 통합 완료가 아니다.

## 검증 방법과 환경

실제 PostgreSQL을 독립 Docker 컨테이너에서 실행하고 schema별 테스트 격리를 사용한다. HTTP TestClient와 실제 HTTP 서버/브라우저 검증을 구별한다. API와 worker 재시작 뒤 같은 ID를 조회한다. 모델 transport와 F2/F3/F4 port 대체는 시험 전용으로 주입한다. runtime에는 누락 외부 기능의 성공을 합성하지 않는다. executor가 검사 코드를 작성하고 Seal ha가 커밋 기준으로 기록한다. 검사 파일·명령은 구현 후 다시 검토한다.
